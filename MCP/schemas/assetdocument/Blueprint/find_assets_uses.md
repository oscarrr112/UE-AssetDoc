# Blueprint reference: find_assets uses

- Examples to copy: `find_assets` with `uses` lists the Blueprints whose graphs use something, with the matching nodes' `NodeGuid`s, without loading them.
- Every term must match; alternatives within a term are separated by `|`. A term is an action key as extracts write it, aliases included (`K2:Add`, `K2:PromotableOperator:Multiply`, `K2:CallArrayFunction` = any array function, `K2:ForEachLoop`, `K2:Get:Health`; a shorter key matches the keys it begins, `*` and `?` match anywhere), a node class (`K2Node_CallArrayFunction` or `/Script/BlueprintGraph.K2Node_CallFunction`, subclasses included), a function (`Array_Length`, `/Script/Engine.KismetMathLibrary:Add_VectorVector`, or a class such as `/Script/Engine.BlueprintSetLibrary` = any of its functions), or an asset path (assets that reference it, any asset type: a Niagara module script, a material function). Example: `["K2:PromotableOperator", "K2:CallArrayFunction|/Script/Engine.BlueprintSetLibrary|/Script/Engine.BlueprintMapLibrary"]`.
- Each row adds `Source` (`Index`: the saved Find-in-Blueprints data, nothing is loaded; `Loaded`: the asset's graphs in memory, for loaded assets with unsaved changes or without index data), `Matches` and `Graphs[{Graph, Nodes[{NodeGuid, Title, Action}]}]` (the `NodeGuid` an extract writes; at most 20 nodes listed).
- The payload adds `Searched` and `NotSearched {Total, Reasons[{Reason, Count, Detail}], Assets[...]}`: graph assets that could not be searched (`NotIndexed`: a Blueprint saved without index data, not loaded; `NotLoaded`: a Sound Cue / Niagara asset, which have no saved node index, not loaded).
