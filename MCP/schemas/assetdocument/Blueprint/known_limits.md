# Blueprint reference: Known issues, rename, orphaned pins

- Known issue: a function graph that overrides a const parent function (`Received_Notify`, `Received_NotifyBegin`, `Received_NotifyTick` of an Anim Notify / Notify State) needs `"Signature": {"Const": true}` (also when other `Signature` flags are listed); with `Const` omitted the apply fails with `Graph.GraphOperationUnsupported` (its const flag is the overridden function's).
- Rename: a name that differs only by letter case (a variable, component, dispatcher, timeline, function/macro/graph, function or dispatcher parameter, custom event) renames the same member, keeping GUIDs, references and links; any other new name is remove + add.
- Orphaned pins: removing a dispatcher input (or a function parameter) while nodes still carry a non-default value on the pin keeps that value as an orphaned pin, as the editor does; the apply succeeds with a `Graph.OrphanedPinDefault` warning naming the node and pin. If the pin is still wired, apply fails with `Graph.OrphanedPinLinked` (the editor's compile error `In use pin ... no longer exists`) and rolls back. To remove an input cleanly, remove the input and the links to it (or reset the pin value) in the same document.
