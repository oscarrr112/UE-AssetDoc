# Blueprint reference: Types, variables, components, timelines

- `BlueprintType`: `"MacroLibrary"`, `"Interface"` or `"FunctionLibrary"` (default `"Normal"`, a Blueprint Class; extract omits it). The type is chosen at creation, by that type's Content Browser factory, and cannot change afterwards (`UBlueprint.BlueprintTypeImmutable`). A Macro Library has only `MacroGraphs` (its `ParentClass` is picked like a Blueprint Class's); an Interface has only `FunctionGraphs` (function signatures) and `ClassDefaults`, parent `/Script/CoreUObject.Interface`; a Function Library has only `FunctionGraphs`, parent `/Script/Engine.BlueprintFunctionLibrary`. The fixed parents are the default when `ParentClass` is omitted. Any other non-empty region fails with `UBlueprint.BlueprintTypeRegionUnsupported`.
- A changed `Type` of a member or local variable that nodes use is the editor's Change Variable Type answered with Yes (no dialog): the nodes take the new type; links the new type cannot keep break, as in the editor, and the compile reports them.
- A map property is a JSON object (`{"Key": value}`) or the editor's text form; both read back equal. An inherited override's `Properties` are the values that differ from the closest parent (the parent Blueprint's own override, as the editor shows it); `null` on an object property (`{"Name": "Combat", "Scope": "Inherited", "Properties": {"MoveTable": null}}`) is an override that clears the parent's value.
- An instanced object property is `{"Class", "Properties"}` (a camera shake's `RootShakePattern`: `{"Class": "/Script/TemplateSequence.SequenceCameraShakePattern", "Properties": {"Sequence": "/Game/Cine/CAS_Shake.CAS_Shake"}}`); its `Properties` are sparse over that class's defaults (a listed default such as `"Scale": 1.0` is accepted, and extract leaves it out).
- `Timelines` (actor-based Blueprints): `[{"Name": "Fade", "Length": 2.0, "AutoPlay": false, "Loop": false, "TickGroup": "PrePhysics", "Tracks": [{"Name": "Alpha", "Type": "Float", "Keys": [{"Time": 0.0, "Value": 0.0}, {"Time": 2.0, "Value": 1.0}]}, {"Name": "Offset", "Type": "Vector", "Keys": {"Z": [...]}}, {"Name": "Tint", "Type": "LinearColor", "Curve": "/Game/Curves/C_Tint"}, {"Name": "Hit", "Type": "Event", "Keys": [{"Time": 1.0}]}]}]`. Track `Type` is Float, Vector, LinearColor or Event; a track has its own `Keys` (one list, or per-channel X/Y/Z or R/G/B/A) or an external `Curve` asset. The timeline node of a new timeline is placed where `UbergraphPages` puts the `K2:Timeline` node of that name.
