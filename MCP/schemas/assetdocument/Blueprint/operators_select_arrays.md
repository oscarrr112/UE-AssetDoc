# Blueprint reference: Operator, Select and array keys

Short operator keys: `K2:Add`, `K2:Subtract`, `K2:Multiply`, `K2:Divide`, `K2:Less`, `K2:Greater`, `K2:LessEqual`, `K2:GreaterEqual`, `K2:EqualEqual`, `K2:NotEqual` (promotable operators), `K2:EqualEnum` / `K2:NotEqualEnum` (the editor's Equal (Enum) / Not Equal (Enum): use them for two enum pins, a promotable `==` turns its second operand into a byte), `K2:SelectFloat` / `SelectInt` / `SelectString` / `SelectName` / `SelectText` / `SelectVector` / `SelectRotator` / `SelectTransform` / `SelectColor` / `SelectObject` / `SelectClass`, `K2:And` / `Or` / `Xor` / `Nand` / `Nor` / `Not`, `K2:Abs` / `AbsInt`, `K2:Min` / `Max` (float) / `MinInt` / `MaxInt`, `K2:Clamp` / `ClampInt`, `K2:Lerp`, `K2:Percent` / `PercentInt`, `K2:NearlyEqual`, `K2:InRange`.

`PinTypes` sets a type picked on the pin itself: the Select node's Index (`{"Index": "int"}`, `"bool"`, `"byte"`, or an enum `"byte:/Game/E_Mode.E_Mode"`, whose option pins are then the enumerators). It is set before links and defaults, and only while the Index is still unlinked; a Select of another index type is a new node. On a promotable operator (`K2:Add`, `K2:Multiply`, `K2:Less`, ...) `PinTypes` are its Pin Conversions, written when its operands differ in type or it is wired to another operator (two unset operators would take the types the order of their links gives them) (`{"A": "struct:/Script/CoreUObject.Vector", "B": "float", "ReturnValue": "struct:/Script/CoreUObject.Vector"}`), set in order before links; a link of another type into an operand promotes it as the editor's drag does.

- Array functions: `K2:CallArrayFunction:/Script/Engine.KismetArrayLibrary:Array_Length` (pin `TargetArray`); `K2:MakeArray` (pins `[0]`, ..., output `Array`). `K2:GetArrayItem` matches two actions (`Graph.ActionAmbiguous`): the message lists each suffixed key with its menu name, owner and pins (`Get (a copy)` / `Get (a ref)`); its index pin is `Dimension 1`, output `Output`.
