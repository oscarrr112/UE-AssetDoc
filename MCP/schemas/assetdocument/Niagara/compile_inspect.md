# Niagara reference: Compile, failures, Inspect

Systems and emitters are read through the Niagara editor's own stack (what the System / Emitter editor shows), without opening an editor, compiling or dirtying the asset. Extract and Inspect results of a system carry `Compile: {Status, Messages}` (`UpToDate`, `UpToDateWithWarnings`, `Dirty`, `Error`), as the editor's toolbar shows it; a compile in flight (an open editor's) is waited for (`Compiling` if it outlasts the wait).

- The apply recompiles the system once (no editor progress UI, shaders not awaited). Errors the system did not have before fail the apply (`Niagara.CompileFailed`); it is rolled back. Errors it already had come back as `Niagara.CompileError` warnings, new compiler warnings as `Niagara.CompileWarning`.
- Apply works with the system open in the Niagara editor: the editor is closed for the apply and reopened (`Niagara.EditorReopened`). Scratch pad edits not applied yet (Apply Scratch enabled) refuse the apply before any change (`Niagara.OpenInEditorUnsavedEdits`): `asset_editor` `close` with `discard_unapplied: true` drops them; `apply_editor` applies them (then `save_assets` and extract again).
- A failed apply changes nothing; a failed Create leaves no asset.
- `inspect_asset_document_target` adds `NiagaraDetails`, summarized by default (per module `Overridden` inputs with their values and the other visible `Inputs` by name; `Library` as counts; a large `Body` as an outline); with `detail: true`: `Modules` (per module every input the stack shows, with `Type`, `Mode` (`Local`, `Linked`, `Dynamic`, `Data`, `ObjectAsset`, `Expression`, `DefaultFunction`, `None` for an input hidden by its visibility condition), `Overridden`, `Static`, `Visible`, `Value`), `Library` (per stack group, the module scripts the stack's "+" menu offers), `Compile` (status and messages attributed to `Emitter` / `Stack` / `Module`), `Lifecycle` (per System State / Emitter State module: `Loops` (whether it loops, `Loop Behavior` `Infinite` / `Multiple`) and its `Loop *` inputs, a default one as `{"Value", "Default": true}`, since extract leaves default inputs out) and `UnsupportedProperties` (Details values that cannot be represented). On a script it adds `Versions`.
