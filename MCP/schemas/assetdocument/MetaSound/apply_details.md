# MetaSound reference: Apply details and errors

- Extract, Apply and Inspect results carry `Compile: {Status, Messages[{Severity, Message, Graph, NodeGuid, NodeGuids?, Source}], Registered}`: the node messages the MetaSound editor's validation shows on every page (`Source: "Validation"`: missing node classes, template nodes without required connections, unconnected required interface outputs), and the errors of building the registered graph into an operator, which the editor only logs when the sound plays (`Source: "Build"`: a cycle through a variable's `Get` and `Set`, ...). `Graph` is the page.
- Inspect adds `Pins` (`{"<page>": {"<key>": {Inputs: ["Name: Type = default"], Outputs: [...]}}}`), `Pages`, `ConfiguredPages` (the pages the project settings define), `RegisteredPage` (the page that plays), `BuildPage` and `InjectedNodes` (keys of the input nodes the editor adds on open, not yet saved in the asset).
- An interface output node that is omitted and has no connection, position or comment is left alone (the editor keeps one per interface output).
- `Interfaces` adds or removes the user interfaces (no default node locations, as in the Interfaces panel); removing one removes its member nodes. Changing a Source's `OutputFormat` (Properties) swaps the output-format interface as the Details panel does; author the new output nodes in the same document.
- Node `Defaults` take the pin's value type; a value equal to the class default is the same as leaving it out.
- Loaded MetaSounds that use this one as a node are re-registered; they are reported as `MetaSound.DependentsUpdated` warnings, and `MetaSound.DependentHasUnsavedChanges` when that left one with unsaved changes. Save them, or reload them, as in the editor.
- Errors fail at their document path and roll the asset back: `MetaSound.UnknownNodeClass`, `UnsupportedNodeClass` (a template or member class name as `Class`), `PinNotFound`, `NodeNotFound` (a source key not in `Nodes`), `InvalidSource`, `IncompatibleConnection`, `ConnectionCycle`, `RerouteType`, `UnknownMember`, `UnknownInterface`, `InterfaceNotModifiable`, `UnknownDataType`, `InvalidMember` (a type the member cannot have, an interface member's `Type`), `InvalidRename`, `InvalidLiteral`, `UnknownWidgetProperty`, `InvalidWidgetValue`, `DuplicateMember`, `DuplicateOutputNode`, `DuplicateSetNode`, `NotReferenceable`, `ReferenceCycle`. A failed Create leaves no asset.
- Node `Configuration`: `Properties` is complete (an omitted setting gets the class's value; `{}` or no `Configuration` is the class's configuration); `Type` is optional and must be the class's configuration struct. The node's pins follow the configuration as in the editor (author the connections of the pins it adds; drop those of the pins it removes). Errors: `MetaSound.InvalidConfiguration` (a class without configuration, another struct, an unknown setting, a value outside its range).
- `Version` (major) of an existing node: setting it to the highest registered major is the editor's Update Node (the node keeps its id; connections and values move by pin name and type; leave out the connections of pins the new version lacks, which the editor drops). Minor versions are not authored (the registry's highest minor is used). A Version that is not the highest registered major, or a node that is not a node class, is refused with `MetaSound.UpdateNodeNotSupported`. A new node needs a registered major: an extraction that shows an unregistered `Version` (the editor shows "class not found") cannot be created as is (`MetaSound.UnknownNodeClass`, the message names the registered version).
- An asset open in the MetaSound editor is edited in place: the open editor shows the applied graph, a failed apply rolls back there too, and the editor's undo history keeps working (an apply clears the undo steps that reference the MetaSound, as for every asset).
- `MetaSound.AudioDeviceRequired`: the graph (or a preset's parent) uses Harmonix Fusion patches, which cannot be registered by an editor without audio (`-NoSound`).
